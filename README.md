# מאמן שפות

אתר לתרגול תרגום משפטים לעברית מספרדית, אנגלית, רומנית וערבית.

## הרצה במחשב

הדרך הקלה: האייקון **"מאמן שפות"** ב-Dock. הוא מפעיל את השרת ברקע (אם הוא לא רץ כבר) ופותח את האתר בחלון Chrome נפרד. השרת ממשיך לרוץ ברקע עד שמכבים את המחשב, והלוג שלו נכתב ל-`~/Library/Logs/spanish-trainer.log`.

את האפליקציה בונים (או בונים מחדש) עם:

```bash
mac/build_app.sh
```

היא נוצרת ב-`~/Applications/מאמן שפות.app`. התיקייה של הפרויקט צריכה להיות מחוץ לשולחן העבודה, למסמכים ולהורדות, כי macOS חוסם אפליקציות מלקרוא משם. לכן הפרויקט נמצא ב-`~/Projects/spanish-trainer`, ועל שולחן העבודה יש קיצור דרך אליו.

אפשרות נוספת: לחיצה כפולה על **`הפעל.command`**. ייפתח חלון Terminal, והאתר ייפתח בדפדפן בכתובת:

**http://127.0.0.1:8124**

כדי לעצור את האתר סוגרים את חלון ה-Terminal.

בהפעלה הראשונה נוצרת תיקיית `.venv` ו-Flask מותקן לתוכה, וזה לוקח כמה שניות. אחר כך האתר עולה מיד.

אפשר להפעיל גם מה-Terminal:

```bash
./run.sh
```

אם macOS חוסם את הקובץ בפעם הראשונה ("לא ניתן לפתוח"): לוחצים עליו קליק ימני, בוחרים "פתח", ואז שוב "פתח".

## בדיקות

```bash
.venv/bin/python -m unittest test_check
```

## קבצים

| קובץ | מה יש בו |
|---|---|
| `spanish_web.py` | כל האפליקציה: מאגר המשפטים, בדיקת התשובות, הנתיבים, וה-HTML של הדפים |
| `test_check.py` | בדיקות לבדיקת התשובות ולנתיבים |
| `run.sh` | מתקין את מה שצריך בפעם הראשונה ומפעיל את האתר על פורט 8124 |
| `הפעל.command` | מפעיל את `run.sh` ופותח את הדפדפן, להפעלה בלחיצה כפולה |
| `Procfile` | להעלאה לשרת (Render / Heroku) עם gunicorn |
